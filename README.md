# TPS Quinto anno script introduttivi PHP

Questo è un semplice repository basato su **PHP**.


## Tecnologie:
- **Apache**
- **PHP**
- **XAMPP**

## Come testare i contenuti:

1. Clona il repository:

git clone https://github.com/MarioGiagnotti/TPS-Quinto-anno-PHP-script-introduttivi.git

oppure fare il Download del file .zip


2. Visualizzazione dell'output

     - Avviare XAMPP
     - Far partire Apache
     - Copiare il contenuto della cartella in C:\xampp\htdocs\php_script_introduttivi
     - Aprire il browser e scrivere sulla barra degli indirizzi:
        **localhost\php_script_introduttivi**
     - cliccare sui link che rappresentano le directory degli esempi
     - cliccare su uno dei file per visualizzare l'output

3. Modifica dei file

    - aprire VSC nella directory C:\xampp\htdocs\php_script_introduttivi
    - modificare i file e testarli come descritto al punto 2

4. Tutti gli esempi sono containerizzati e scaricabili da https://hub.docker.com/repositories/m76g
